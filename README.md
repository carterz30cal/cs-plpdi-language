# cs-plpdi-language - INHALE
a small lazyish interpreted language that aims to achieve some of the flexibility and niceties of haskell whilst maintaining the readability of a procedural language

our scope is determined using calls and curly brackets

## inspo
mostly haskell, some c#, some python
